# 本地 B224 单序列计时（2026-08-27）

## 条件

- 序列：`train_sim/seq_0011`，450 帧，1440×720。
- 权重：`SUTRACK_b224_ep0180.pth.tar`，官方 B224 权重。
- 设备：Intel Core Ultra 5 225H CPU；本次没有调用 Arc 130T 或 AI Boost NPU。
- 入口：`scripts/eval_official.py --tracker sutrack --force-cpu --no-sutrack-amp`。

## 实测

| 指标 | 值 |
|---|---:|
| 序列推理耗时 | 108.4 s |
| tracker FPS | 4.19 |
| 端到端 FPS | 4.15 |
| P50 延迟 | 237.5 ms |
| P95 延迟 | 271.1 ms |
| AUC | 0.2604 |
| SR | 0.2940 |

这是失败场景上的短序列诊断，不是提交成绩。GPU 归档结果同序列为 AUC 0.2641/SR 0.2984/E2E 29.87 FPS，CPU结果基本复现了行为，但数值会有轻微差异。

## 结论

当前本机可以跑完整小序列，但 CPU 速度约 4 FPS。Arc/NPU 尚未进入推理链；要测它们，需先安装 OpenVINO/DirectML 并导出 B224 的静态 per-frame ONNX 图。
