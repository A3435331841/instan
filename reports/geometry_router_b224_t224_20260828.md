# 几何路由 B224/T224 赛马记录（2026-08-28）

## 目的

在不按序列名称、不读取 GT、不查离线成绩表的前提下，验证一个可部署的“B224 精度主干 + T224 快速专家”方案。路由只在首帧根据协议提供的 BFoV 角度和纬度做一次决定，之后每帧只运行一个模型。

## 路由规则

- `fov_h <= 6°` 且 `|latitude| < 85°`：选择 T224；
- `10° <= fov_h < 15°` 且 `|latitude| < 65°`：选择 T224；
- 其余情况：选择带自适应几何搜索因子、极小高纬模板保护和低质量高模板分支的 B224。

规则只使用 `init.txt` 中的 BFoV，不使用序列名、GT 后续帧或历史离线结果。T224 和 B224 的 OpenVINO 图输入尺寸相同（224 搜索、112 模板），不会在同一帧并行运行两个模型。
