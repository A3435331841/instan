ODTrack 官方数据微调族（ft_ep1-8 / ft_v4_ep1-6）

用官方 130 序列（train95/valid35 划分，valid 绝不训练）对 ODTrack 微调，产出 ft_ep1-8 与 failure-balanced v4/v5 系列。目标是域自适应，但 medium 30 上无一超越基线的量级突破，作为组件保留。

🏗️架构设计

官方数据 train95（19/19/19/19/19 五折 OOF）→ 三平铺样本流 + 随机经度 roll → ODTrack 热启动（LR 1/10, 20 epoch）→ 逐 epoch checkpoint → representative/medium 快评通道。v4/v5 引入 failure-balanced 采样（sampler 读 GRT360_TRAIN_MANIFEST）。

🔬技术细节

**数据管道**：官方 130 序列按 seed 20260824 确定性划分 train95（32 real + 63 sim）/ valid35（15 real + 20 sim）；`make_official_split.py` 产出 split.json + seqlist；`prepare_finetune_data.py` 把 video+BFoV 转成三平铺训练样本流并**按消失段切分子序列**（官方数据有 11% 消失帧 (0,0,0,0)，评测 runner 掩码跳过，训练按消失段切割防止污染）。**训练清单**（`training_manifest.py`）：`build_spherical_training_manifest` 生成 leakage-safe 的 train95 清单，real/sim 采样质量平衡（sim 83 条多为 450/900 帧，real 47 条 ~1600 帧），5 折 OOF（19/19/19/19/19）支撑交叉验证；valid35 在任何清单中排除。**训练配置**（finetune_official.yaml / finetune_spherical_v5.yaml）：PRETRAIN=ODTrack_ep0300.pth.tar 热启动，LR=0.00001（原 0.0001 的 1/10），EPOCH=20，LR_DROP_EPOCH=15，SAMPLE_PER_EPOCH=15000，AMP；v5 用 failure-balanced 采样（sampler 读 GRT360_TRAIN_MANIFEST 的 capped 权重，困难序列更高采样概率），并加随机经度 roll 增强。**依赖补丁**：`torch._six`、visdom 桩、loader 去掉 torch._six 引用（py3.8 时代代码适配 py3.12）。

🧠机理分析：为什么在长处场景有效

**为什么微调没有突破基线**（结构性归因）：①**数据规模**——train95 只有 95 条序列（32 real + 63 sim），域漂移信息有限；ODTrack 原始训练集（LaSOT/GOT-10k/TrackingNet/COCO）规模大 2-3 个数量级，95 条官方数据不足以撼动预训练权重的主导地位。②**LR 1/10 的保守策略**——热启动 + 低学习率防止灾难性遗忘，但同时也限制了新域特征的吸收速度，20 epoch × 15000 samples/epoch 的预算偏小。③**三平铺输入已是最优适配**——ODTrack 已通过三平铺获得 360 域的大部分收益，微调是在『已经吃饱』的基线上再加菜，边际收益递减。**为什么 ft_v4_ep4/5 在 real 段略好**：failure-balanced 采样（困难序列更高权重）让模型在真实困难序列上更充分训练——real AUC 0.448/0.417 接近 sutrack_b224（0.4435），证明『训练数据平衡策略』方向正确。**为什么 representative 与 medium 不一致**：representative 9 条精选序列（难度均衡）放大了微调 checkpoint 在特定场景的增益；medium 30（更接近真实分布）拉平了差异——这正是项目用 medium 作为最终 gate 的机理。

⚖️优缺点

优点

  • 建立了无泄漏划分（valid35 永不训练）与五折 OOF 纪律
  • failure-balanced v5 是有据可依的训练策略创新
  • 多个 checkpoint 在 representative 上进入 core_keep（组件价值）
  • ft_v4_ep4/5 在 medium real 段 AUC 0.448/0.417 接近 sutrack_b224

缺点

  • medium 30 上无任何微调版超过 ODTrack 0.5882 基线
  • FPS 普遍 11-16（低于基线 29.9 与 sutrack 26）
  • train95 只有 95 条序列，域漂移收益有限
  • ft_ep1-4 / v4_ep2/3/6 在 representative 上被 drop

🎯适用场景

域自适应候选；作为融合中的 sim/hard 专家或速度基线 peer；v5 训练仍在进行中（GPU0）。
