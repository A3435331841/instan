🏗️架构设计

环绕 padding（几十行手写进 patch embedding）+ 畸变加权损失（用于微调）+ 长期 object pointer 记忆；状态机『跟踪↔检测』切换。

🔬技术细节

**PanoSAM2（arXiv 2604.07901，未开源）**：面向全景的 SAM2 适配，三大技术点：①**环绕 padding 解码器（circular padding decoder）**——在 patch embedding / attention 阶段对 ERP 接缝做循环 padding，使接缝两侧获得连续感受野（我们可几十行手写进 ODTrack 的 patch embedding，与三平铺互补）；②**畸变加权损失（distortion-weighted loss）**——按 ERP 纬度畸变权重（cos(lat) 面积比）重新加权损失，抑制极区过采样（可并入官方数据微调的损失）；③**长期 object pointer 记忆**——跨长时段的显式目标指针，缓解 SAM 短期记忆漂移。360VOTS 上 +5.6（J&F）。**OmniTrack++（arXiv 2511.00510）**：置信度驱动的『端到端跟踪 ↔ 检测全局模式』状态机——低置信切全局检测模式、恢复后切回端到端跟踪；其模式切换逻辑与我们 adaptive_spherical 的 NORMAL/LOST/VERIFY 同构，可作为状态机调参的对照参考。**引用纪律**：两文均未开源、数字为论文口径，答辩引用需注明『调研转述』。

🧠机理分析：为什么在长处场景有效

**为什么环绕 padding 对全景跟踪有效**（结构归因）：ERP 接缝两侧在物理上是连续场景（经度 0° 与 360° 相邻），但标准 CNN/transformer 的 padding 把接缝当不相关边界——patch embedding 在接缝处截断感受野，目标跨界时特征被『切开』。环绕 padding（circular）把接缝两侧的像素循环拼接，使接缝处感受野连续，模型能看到『完整的跨界目标』——这与我们三平铺解决同一问题，但**粒度更细**（在特征层解决 vs 输入层解决），且不增加 3 倍输入开销（可叠加在三平铺上）。**为什么畸变加权损失有效**：ERP 的纬度畸变使极区像素面积被拉伸（cos(lat) 面积比），标准损失在极区过采样、赤道欠采样；按 cos(lat) 反权重可让模型公平学习各纬度——小目标/极区序列的增益来源。**为什么 OmniTrack++ 状态机与我们同构**：置信度驱动的『跟踪↔检测』模式切换 = 我们的 NORMAL/LOST/VERIFY 四态；文献独立得出相同结论（低置信切全局模式），为 adaptive_spherical 的架构合理性提供外部背书。**引用纪律**：两文未开源，数字（+5.6 J&F）为论文口径，答辩引用注明『调研转述』。

⚖️优缺点

优点

  • 环绕 padding 零成本可落地（低工程量）
  • 畸变加权损失可并入微调
  • 状态机设计与 adaptive_spherical 同构可对照

缺点

  • 均未开源，仅方向借鉴
  • PanoSAM2 数字为论文口径需核实

技术路线借鉴：环绕 padding 可手写进 ODTrack patch embedding；状态机可对照 adaptive_spherical。
