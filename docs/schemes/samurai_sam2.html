🏗️架构设计

SAM2.1 官方权重 + Kalman 运动记忆；不解决全局找回（只在预测邻域内选 mask）；360VOT 工具包自带 mask2Bfov 转换。

🔬技术细节

**SAMURAI（arXiv 2411.08372，『SAMURAI: Adapting Segment Anything Model for Zero-Shot Visual Tracking with Motion-Aware Memory』）**：零训练（zero-shot）长时跟踪器——复用 SAM2.1 官方权重，关键改动是把 SAM2 的朴素记忆替换为**运动感知记忆（motion-aware memory）**：用 Kalman 滤波预测目标运动，将预测位置作为记忆 token 的定位先验，显著降低遮挡/相似物干扰下的错误传播。LaSOT 74.2 / GOT-10k 81.7 / **OTB100 71.5（与比赛同 OTB 协议）**，全遮挡属性 +12.7%，~4GB 显存 4090 实时。**360 域关键点**：①SAM2 的 occlusion head 输出可见性分数 = 免费判丢信号；②任意帧 `add_new_points_or_box` 重新注入 = 原生找回接口；③但 SAMURAI 只在预测邻域内选 mask，**不解决全局找回**——需配合多切平面检测做 LOST 分支。**mask→BFoV**：360VOT 工具包自带 mask2Bfov/mask2Bbox，取最大连通域防遮挡碎块撑爆外接框。**域警告**：PanoSAM2（arXiv 2604.07901）证明 SAM2 在 360VOTS 有 ~60 J&F 基本盘但接缝/畸变是主要损失源。

🧠机理分析：为什么在长处场景有效

**为什么遮挡/长时最强（LaSOT_ext 61.0 领先 7 点）**（结构归因）：SAM2.1 是 promptable 分割基础模型，其记忆机制（memory bank）在遮挡时保留目标历史 mask；SAMURAI 的关键升级是**运动感知记忆**——Kalman 滤波预测目标位置作为记忆 token 的定位先验，遮挡恢复时 SAM2 的 mask 选择被运动先验引导，避免被遮挡物/相似物带偏（全遮挡 +12.7% 即此机理）。**为什么是 recapture 失锁分支的理想升级**：①SAM2 的 occlusion head 输出可见性分数——比我们 recapture 的 NCC 代理判丢信号更本质（直接建模『目标是否可见』）；②`add_new_points_or_box` 可任意帧重新注入目标 = 原生找回接口，无需自研重检测器；③mask→BFoV 转换用 360VOT 工具包现成函数（取最大连通域防碎块撑爆外接框）。**为什么不能直接当主干**：SAMURAI 只在预测邻域内选 mask（无全局找回），且 ERP 全景的接缝/畸变是 SAM2 的主要损失源（PanoSAM2 证明）——需配合多切平面检测 + 环绕 padding 才能用于全景。**定位**：recapture v2 的『判丢信号双分支 + 重捕获』最强候选，而非提交主干。

⚖️优缺点

优点

  • 零训练直接可用
  • 遮挡/长时最强（LaSOT_ext 61.0 领先 7 点）
  • 免费判丢信号 + 原生找回接口
  • 360VOT 工具包转换现成

缺点

  • 不解决全局找回（需配合多切平面检测）
  • SAM2.1 栈较大，断网镜像体积压力
  • PanoSAM2 证明 SAM2 在 360VOTS 接缝/畸变是主要损失源

🎯适用场景

recapture 失锁分支的最强候选：LOST 时用 SAM2 在切平面视角选 mask → mask2Bfov；或作为判丢信号双分支。
