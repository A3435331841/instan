🏗️架构设计

BFoV 几何（球面→切平面投影）+ 恒定角速度状态预测 + NCC 局部匹配 + 判丢/重检测骨架。先验驱动，无学习型组件。

🔬技术细节

**几何管线**：BFoV 定义为中心 (lon,lat) + 视锥 (fov_h, fov_v)。ERP→BFoV 用 gnomonic 投影（切线平面）：对切平面角偏移 (du,dv)，方向向量 v = c + tan(du)·east + tan(dv)·north，其中 c/east/north 由中心方向与北向叉积构造的右手系（极区退化时 east 取固定方向）。反投影 erp_bbox_from_bfov 由视锥四角方向向量经 _unit_to_lonlat 得到 (lon,lat) 后映射到像素 x=(lon+180)/360·W, y=(90-lat)/180·H。**状态预测**：恒定角速度模型（球面圆周运动假设），对 lon 线性外推，lat 保持——该假设在真实 4K 序列第 7-8 帧即失效（漂移根因）。**NCC 匹配**：模板与搜索图灰度化 + highpass(σ) 预处理后逐像素归一化互相关，峰值 (py,px) 用 _subpixel_peak 亚像素精化；搜索图在 BFoV 窗口内以 sr_ratio 决定 FoV。**判丢**：PSR（峰值旁瓣比）与 APCE 双阈值（lost_psr=3.0, lost_apce=0.5）。超参：patch_size=255, sr_ratio=3.0~6.0, template_size=127, search_scale=2.0, lr=0.02, hp_sigma=3.0。

🧠机理分析：为什么在长处场景有效

**为什么在合成/简单场景有效**：NCC 是无参的像素级模板匹配，其成功条件恰好是合成数据的特性——目标外观帧间几乎不变、光照恒定、无遮挡、目标在搜索图中占比足够大（>10%）。此时归一化互相关在数学上就是最优匹配（白噪声假设下的 ML 估计），且球面几何（gnomonic 投影）保证了切图无畸变，匹配精度可达亚像素（_subpixel_peak 精化）。**为什么在真实 4K 全景失效**（结构层面三重因果）：①NCC 的模板是首帧原始像素，真实目标外观变化（形变/光照/视角）使相关性迅速衰减；②4K 全景小目标（<30px）在切图中占比 <5%，搜索窗内峰值被背景噪声淹没；③恒定角速度状态预测是开环外推，第 7-8 帧起预测中心偏离目标，而 NCC 只在预测中心邻域搜索——定位误差与匹配误差正反馈放大。**结论**：NCC+BFoV 的失败是『无学习能力 + 开环状态预测』两个结构性缺陷叠加，而非参数问题（参数搜索已证明天花板）。

⚖️优缺点

优点

  • 零依赖纯 numpy/Pillow/scipy，CPU 可跑
  • 球面几何模块（BFoV/切平面投影）成为后续全部方案的几何底座
  • 合成数据（equator/crossing/pole/occlusion）验证了跨界与极区处理的正确性

缺点

  • NCC 无学习能力，真实 4K 目标（<30px）占比 <5% 时完全失效
  • BFoV 恒定角速度状态预测第 7-8 帧累积漂移
  • 6 序列 mean AUC 仅 0.11，远低于 Stage 2 目标 0.45

🎯适用场景

仅适合合成数据/低难度验证；真实全景跟踪不可用。但球面几何与判丢骨架被 ODTrack 三平铺与 recapture 外挂继承。
