NCC 基线（BFoV 框架）

经典方法 · 几何框架 · Stage 1-2（2026-07）
项目最早的端到端原型：BFoV（球面视锥）几何 + 归一化互相关（NCC）局部跟踪器，合成数据上跑通，真实数据全面失败。
0.11; 0.12
已废弃（关键反面教材）

BFoV + VitTrack（框架漂移验证）

经典方法 · 几何框架 + 学习跟踪器 · Stage 2（2026-07-25 前后）
在 BFoV 框架上接入学习型跟踪器 VitTrack（ONNX），验证了『几何框架 + 学习跟踪器』策略对单序列有效（0036: 0.05→0.74），但整体被框架漂移拖垮。
0.25; 0.26
历史/本地验证方案

Direct ERP + VitTrack（全帧直连）

全帧跟踪 · 历史方案 · Stage 2-3（2026-07-25 ~ 08）
绕过 BFoV 切图，直接在全帧 ERP 上跑 VitTrack。精度与 BFoV 持平但速度提升 20 倍、彻底消除漂移——是『全帧直连』路线的首个证据。
0.26; 0.26
已降级（历史推荐→全量翻车）

LightFC ONNX（轻量全帧跟踪器）

全帧跟踪 · 轻量 ONNX · Stage 2-3（2026-07-25 ~ 08-09）
LightFC（特征关联轻量跟踪器）经 ONNX 双子图接入全帧路线。代表序列 AUC 0.618 一度为推荐方案，120 序列全量评测仅 0.3116——小样本数字的典型教训。
0.618; 0.3116
已提交（初赛成绩冻结）

ODTrack ERP 三平铺（初赛提交 · 精度冠军）

全景适配 · 三平铺 · Stage 3（2026-08-09 ~ 08-14）
把 ODTrack（自回归密集时序跟踪器）适配到 ERP 全景：目标区域三平铺展开送入模型，成为 120 序列赛马冠军并作为初赛提交镜像。公开文献事实 SOTA（超 AiATrack-360 0.534 约 +8.4%）。
0.5792; 0.6532
保留（高速基线/蒸馏起点）

UETrack ERP-wrap（高速基线）

全景适配 · ERP 环绕 · Stage 3（2026-08-09 ~）
UETrack（统一高效跟踪器）以 ERP-wrap 形式接入（搜索图环绕 padding），120 序列 AUC 0.5143 / 57.16 FPS，速度是 ODTrack 的 6 倍多，是快路径与知识蒸馏学生模型的起点。
0.5143; 0.5776
验证中（组件候选）

ODTrack 官方数据微调族（ft_ep1-8 / ft_v4_ep1-6）

域微调 · 训练 · 决赛冲刺（2026-08-22 ~）
用官方 130 序列（train95/valid35 划分，valid 绝不训练）对 ODTrack 微调，产出 ft_ep1-8 与 failure-balanced v4/v5 系列。目标是域自适应，但 medium 30 上无一超越基线的量级突破，作为组件保留。
0.4535~0.4817; 0.4962~0.5279
核心候选（精度/快路径双线）

SUTrack（B224 / T224）

通用 SOT · 自回归 · 决赛冲刺（2026-08-24 ~）
SUTrack（自回归单目标跟踪器，AAAI 2025）B224/T224 双尺寸接入。**B224 官方 all130 首超 ODTrack 基线（AUC 0.6113 vs 0.5882）**，成为当前最强单模型；T224 是快路径核心（39 FPS）。与 ODTrack 清晰互补（36 修复 vs 16 退步序列）。
0.6113; 0.7223
真实场景专家（保留）

LoRAT（B378/L378，LoRA 高效跟踪）

通用 SOT · LoRA 微调 · 决赛冲刺（2026-08-21 ~）
LoRAT（ECCV 2024，LoRA 参数高效微调跟踪器，码基最现代）接入。representative 上精度最强（AUC 0.6021 / SR 0.7275），但 medium 速度慢（8.7 FPS）且泛化衰减，定位为真实场景精度专家而非主干。
0.6021; 0.7275
已实测（drop）

ODTrack + Recapture 外挂（判丢 + 球面重捕获）

系统级外挂 · 可靠性门控 · 2026-08-10 ~ 08-14
给 ODTrack 装『判丢 + 全图找回』外挂：ReliabilityGate（多信号融合判丢）+ TemplateMemory + 多切平面重检测。针对 10 条失锁序列设计，目标是救回一半（+0.02~0.04），但 representative 实测 AUC 0.3981 被 drop。
0.3981; 0.4007
已实测（增益有限）

融合族（fusion_2way ~ 8way）

多模型融合 · 决赛冲刺（2026-08-24 ~）
对全部候选做组合融合（2/3/4/5/6/8-way，含 v1v4/ep7 变体）。30/30 最优 fusion_5way AUC 0.522，仅比单模型最好（sutrack_b224 0.4919）高 3 个点，远低于 oracle 上限 0.5779。
0.522; 0.522
已实测（保守路由保护教师）

Causal-DTP-ERP（教师-学生路由）

多模型路由 · 创新实验 · 2026-08-10 ~
教师（ODTrack 三平铺）+ 学生（UETrack ERP-wrap）+ Scout（LightFC）三模型，Scout 判定难度后决定是否调用教师。当前保守路由保护 ODTrack 精度（AUC 与 ODTrack 相同 0.5792），未带来增量。
0.5792; 0.6532
开发中（v1 未过 micro gate，v2 排队）

adaptive_spherical（自适应球面状态机）

自适应系统 · Phase 2 创新 · Phase 2（2026-08-26 ~）
Phase 2 的核心自研：NORMAL/SUSPECT/LOST/VERIFY 四态状态机 + 球面运动证据 + anchor 校验 + 稀疏专家 token 预算 + 延迟自适应调用 + 状态化专家片段。首个 micro gate（seq_0046 前 80 帧）复现 T224 结果但多付 20% B224 探测开销，v1 未晋升。
0.3623; 0.5570
已实现（配置存在，未进入赛马主线）

Spherical Memory（球面记忆）

全景专项 · 记忆增强 · 2026-08 中旬
自研球面记忆模块（spherical_memory 配置/模型存在：24 通道，模板 64，update_threshold 0.45），用于模板更新与球面状态记忆，作为可选 tracker 接入。未出现在 medium/representative 赛马结果中。
channels=24, template_size=64; 未进入赛马主线
调研（未接入）

SPMTrack（CVPR 2025，LaSOT 最高可复现）

调研候选 · 未实跑 · 调研 2026-08-21
CVPR 2025 通用 SOT，LaSOT AUC 77.4/76.8/74.9（G/L/B），公开可复现最高。LoRAT 码基同源，接入成本预估可控，但 360 域直接证据缺失，优先级低于三平铺适配收益。
77.4 / 76.8 / 74.9; 未公布

SAMURAI / SAM2 系（长时跟踪与重捕获）

调研候选 · SAM 生态 · 调研 2026-08-21
SAMURAI（SAM2.1 + Kalman 运动记忆，零训练）：LaSOT 74.2 / GOT-10k 81.7 / OTB100 71.5（与比赛同协议），全遮挡 +12.7%。SAM2 occlusion head 输出可见性分数 = 免费判丢信号，任意帧可重新注入 = 原生找回接口。
74.2; 71.5
调研（对照基线）

调研对照 · 文献标杆 · 调研 2026-08-21

LoRAT-360 官方微调（文献证据）

调研对照 · 文献证据 · 调研 2026-08-21
文献中唯一做过 360 微调的方法：LoRAT 接入 360VOT 官方框架微调后 0.461→0.495（+7% 相对），仍低于我们的 0.5792。证明『ERP 三平铺适配收益 > backbone 差距』。
0.495; +7%

PanoSAM2 / OmniTrack++（方向借鉴）

调研借鉴 · 未开源 · 调研 2026-08-21
PanoSAM2（arXiv 2604.07901，未开源）：环绕 padding 解码器（接缝连续感受野）+ 畸变加权损失 + 长期 object pointer，360VOTS +5.6。OmniTrack++（arXiv 2511.00510）：置信度驱动『端到端跟踪 ↔ 检测全局模式』状态机。
360VOTS +5.6; 状态机模式切换
调研（部分落地 cu128 镜像）

RTX 5090 部署加速（NVDEC / GPU 预处理 / BF16 / compile）

工程加速 · 部署优化 · 调研 2026-08-21 ~
瓶颈定量归因：8.99 FPS 中每帧 ~111ms 约 70ms 在 4K CPU 软解 + 三平铺整图拷贝 + CPU 裁剪。NVDEC 硬解 + GPU 预处理 + BF16 + torch.compile 预计 60-80+ FPS（零/近零精度损失）。
8.99 FPS; 32 FPS@2080Ti
